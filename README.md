# AfriShop

## Description
AfriShop est un site vitrine présentant des produits africains authentiques, locaux et de qualité : mode africaine, artisanat et produits locaux.

## Auteur
HALIMATA ADOUM

## Technologies utilisées
- HTML5
- CSS3 (Flexbox)
- Git et GitHub (versionnage)
- Visual Studio Code

## Instructions de lancement
1. Cloner le dépôt ou télécharger le projet :
   `git clone https://github.com/halimata22/AfriShop.git`
2. Ouvrir le dossier `AfriShop`.
3. Double-cliquer sur le fichier `index.html` pour l'ouvrir dans un navigateur.
